Zustral は、業務の10進計算とバッチ処理のためのプログラミング言語です。COBOL の代わりになる、小さくて明示的な言語を目指しています。

GitHub で見る Decimal 型を見る

4つの柱

01

コンパクトな COBOL の代替

汎用言語は目指しません。用途を、金融をはじめとする業務の10進計算とバッチ処理に絞ります。

02

メモリ安全

Austral の線形型を受け継ぎ、GC に頼らずにメモリ安全性を保証します。

03

明示的であること

書かれていないことは起きません。暗黙の変換、隠れた制御フロー、見えないメモリ確保はありません。

04 — 核

金銭計算のバグを言語で防ぐ

10進計算の誤りを、プログラマの注意力ではなく型システムで、実行前に弾きます。

Decimal[P, S]

組み込みの10進固定小数点型です。P は精度（全体の桁数、1〜38）、S はスケール（小数点以下の桁数）です。値は符号付き128ビット整数の係数で持つので、大きさは16バイト固定で、ヒープは使いません。

-- unit_price: Decimal[9, 0]、quantity: Int32、discount: Decimal[11, 0]
let gross: Decimal[19, 0] := unit_price * quantity;
let subtotal: Decimal[19, 0] := gross - widen(discount);
let tax: Decimal[11, 0] := round(subtotal * 0.10, TowardZero());  -- 円未満切り捨て
let per_person: Decimal[11, 0] := divide(subtotal, 3, TowardZero());
let total: Decimal[20, 0] := widen(subtotal) + widen(tax);

既定の丸めモードはない

桁を落とす演算には、7つある RoundingMode のどれかを必ず書きます。「現在の丸めモード」のような大域の状態もありません。

暗黙の変換はない

P か S が違えば別の型です。桁を広げるのは widen、狭めるのは exact か round で、どれも明示して書きます。

リテラルは丸めない

Decimal[7, 2] の位置に 1.234 と書くとコンパイルエラーになります。表せない値は黙って丸めません。

黙って間違える式を、コンパイル時に弾く

let interest: Decimal[11, 0] := round(balance * (days / 365), TowardZero());  -- コンパイルエラー
let interest: Decimal[11, 0] := divide(balance * days, 365, TowardZero());     -- こう書く

整数の / は小数部を黙って切り捨てるので、days / 365 は365日未満なら 0 になります。金額の式でこれが通ると、間違った金額が黙って出ます。

失敗の扱いを選べる

演算子と checked の付かない演算は、桁あふれするとメッセージを出して止まります。checked の付く演算は Option を返すので、不正なデータで止めたくないバッチでは、None のレコードだけをよけられます。

let stored: Option[Decimal[11, 0]] := checkedRound(balance * rate, TowardZero());

Austral から受け継ぐ機能

線形型

メモリやファイル、DBのハンドルを、実行時のオーバーヘッドなしに安全に扱えます。二重 free や解放後の使用を防ぎます。

ケイパビリティ

低水準の機能へのアクセス権を細かく与え、依存ライブラリが触れる資源を制限します。サプライチェーン攻撃に強くなります。

型クラス

Haskell 由来の型クラスで、有界なアドホック多相を使えます。

安全な算術

Ada と同じく、オーバーフローでトラップする演算と剰余算術を別々に持ちます。

代数的データ型

ML や Haskell と同じ代数的データ型を、網羅性の検査つきで備えます。

持たない機能

  • ガベージコレクション
  • デストラクタ
  • 例外
  • 暗黙の関数呼び出し
  • 暗黙の型変換
  • 暗黙のコピー
  • グローバルな状態
  • サブタイピング
  • マクロ
  • リフレクション
  • @アノテーション
  • 型推論（型の情報は一方向に流れる）
  • 初期化されていない変数
  • x++ のような増減の演算子
  • 言語組み込みの async
  • 関数のオーバーロード（型クラスを除く）
  • 算術演算子の優先順位
  • 変数のシャドーイング

例

module body Fib is
    function fib(n: Nat64): Nat64 is
        if n < 2 then
            return n;
        else
            return fib(n - 1) + fib(n - 2);
        end if;
    end;

    function main(): ExitCode is
        print("fib(10) = ");
        printLn(fib(10));
        return ExitSuccess();
    end;
end module body.
$ austral compile fib.aum --entrypoint=Fib:main --output=fib
$ ./fib
fib(10) = 55

コンパイラの実行ファイル名は、Austral から受け継いだ austral のままです。

ビルド

Nix があれば次だけで済みます。

$ git clone https://github.com/seiei-sogen/zustral.git
$ cd zustral
$ nix-shell
$ make

Nix を使わない場合は、OCaml 4.13.0 以上と opam、dune、C コンパイラが要ります。

$ opam switch create austral 4.13.0
$ eval $(opam env --switch=austral)
$ opam install --deps-only -y .
$ make
$ ./run-tests.sh
