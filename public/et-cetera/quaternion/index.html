1軸と角度

どんな3D回転も「ある軸のまわりに、ある角度だけ回す」の一言で言い切れる。クォータニオンは、その軸 n と角度 θ を4つの数にたたんだもの。

w は角度だけで決まる cos(θ/2)。x, y, z は軸 n の向きに sin(θ/2) を掛けたもの。だから4つの数の2乗和はいつも 1 になる。

θ ではなく θ/2 なのは、ベクトル v を回すときに v′ = q v q−1 と q で両側からはさむから。片側が θ/2 ずつ受け持って、合わせて θ になる。

2360°では元に戻らない

機体を 360° 回すと見た目は元通りになる。ところが q は (−1, 0, 0, 0) で、出発点の (1, 0, 0, 0) とは符号が逆。q まで元に戻るのは 720° 回したときになる。

「ひねりをほどく」は θ が 720° のときだけ押せます。

機体が回るあいだ、q は文字盤の上を半分の角度しか進まない。

q = (0.707,0.707,0.000,0.000)

−q = (−0.707,−0.707,0.000,0.000)

q と −q は同じ姿勢を表す。(−q) v (−q)−1 = q v q−1 で、マイナスが2つ打ち消し合うから。1つの姿勢に2つの q が対応するので、これを二重被覆と呼ぶ。

板の列は「機体が何回ひねられたか」を覚えている。360° のひねりは、両端を固定したままではどうやってもほどけない。720° のひねりはほどける。q が −1 で終わるか 1 に戻るかの違いが、そのまま板の列に現れている（ディラックのベルトと呼ばれる実験）。

3オイラー角とくらべる

オイラー角は、3つの軸を決まった順番で回して姿勢を表す。直感的だが弱点が2つある。ある姿勢で軸が重なってしまうことと、2つの姿勢のあいだをなめらかにつなげないこと。

3本の軸が別々の向きを向いているので、機体をどの向きにも回せる。

q = (0.951,0.255,0.168,0.045)

輪は外側から X・Y・Z の順に入れ子になっている。中間の輪を 90° 倒すと、内側の輪の軸（青）が外側の輪の軸（赤）に重なる。3つあったはずの回転の自由が2つに減る。これがジンバルロック。

クォータニオンは回転を「1本の軸と1つの角度」のまま持っているので、軸どうしが重なってつぶれる姿勢がない。上の q は、ロックした瞬間もふつうに1つの値を指している。
