1回転では戻らない。2回転で元通り

機体を1回転（360°）させると、見た目は最初と同じ向きに戻る。ところが4つの数は戻っていない。全部の符号が反対になっている。もう1回転して、合わせて2回転（720°）したとき、やっと数も元に戻る。

数が戻っていないことは、機体を見ているだけではわからない。そこで下の3Dでは、壁と機体を板の列でつないで、ねじれとして見えるようにした。

「ねじれをほどく」は θ が 720° のときだけ押せます。

機体が回るあいだ、文字盤の針は半分の角度しか進まない。

q = (0.707,0.707,0.000,0.000)

−q = (−0.707,−0.707,0.000,0.000)

やってみよう

  1. 「360°にする」を押す。機体は最初と同じ向き。でも q は (−1, 0, 0, 0) で、板の列は1回ねじれている。
  2. 「ねじれをほどく」を押そうとしても押せない。1回ぶんのねじれは、壁と機体を動かさないかぎり絶対にほどけない。
  3. 「720°にする」を押す。q が (1, 0, 0, 0) に戻る。板の列は2回ねじれている。
  4. 「ねじれをほどく」を押す。壁も機体も動いていないのに、ねじれがするすると消える。

自分の腕でもためせる

手のひらを上に向けて、その上に水の入ったコップが載っているつもりになる。こぼさないように手のひらを上に向けたまま、わきの下をくぐらせて手を1回転させる。腕がねじれて、ひじが上を向く。そこから同じ向きに、今度は頭の上を通してもう1回転させる。腕のねじれが取れて、最初の姿勢に戻る。

手のひらは1回転で元の向きに戻るのに、腕は2回転しないと戻らない。板の列で起きていたのは、これと同じこと。

同じ向きに、数が2つある

q と、その符号を全部反対にした −qは、まったく同じ向きを表す。文字盤でいうと、針の先と、そのちょうど反対側の白丸。1つの向きに対して数が2通りあるので、これを「二重被覆」と呼ぶ。

q は「向き」だけでなく、「そこまでに何回ねじったか（奇数回か偶数回か）」まで覚えている数、と考えるとわかりやすい。

式で見たい人へ

ベクトル v を回す式は v′ = q v q−1。ここで q を −q に替えると、

(−q) v (−q)−1 = q v q−1

となって、マイナスが2つ打ち消し合う。だから q と −q は同じ回転になる。

板の列の実験は「ディラックのベルト」と呼ばれている。ほどけるかどうかは、q が −1 で終わるか 1 に戻るかで決まる。
