360°では元に戻らない

機体を 360° 回すと見た目は元通りになる。ところが q は (−1, 0, 0, 0) で、出発点の (1, 0, 0, 0) とは符号が逆。q まで元に戻るのは 720° 回したときになる。

「ひねりをほどく」は θ が 720° のときだけ押せます。

機体が回るあいだ、q は文字盤の上を半分の角度しか進まない。

q = (0.707,0.707,0.000,0.000)

−q = (−0.707,−0.707,0.000,0.000)

q と −q は同じ姿勢を表す。(−q) v (−q)−1 = q v q−1 で、マイナスが2つ打ち消し合うから。1つの姿勢に2つの q が対応するので、これを二重被覆と呼ぶ。

板の列は「機体が何回ひねられたか」を覚えている。360° のひねりは、両端を固定したままではどうやってもほどけない。720° のひねりはほどける。q が −1 で終わるか 1 に戻るかの違いが、そのまま板の列に現れている（ディラックのベルトと呼ばれる実験）。
